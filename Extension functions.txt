
sqlite functions:

-Executes a function found in the global lua table
-function: string.format, CRC64, etc
-args: arguments passed to the lua function
array LuaFunction(function, args...)

-Registers an aggregate function
-function should be defined as function(isFinished, context, arg1, arg2, ...)
-if isFinished is true the function should return the aggregated value
-Context is a table thats passed to each call of the function
-Context is destroyed when aggregation is finished
-if isFinished is true then the additional parameters are nil, the function should just return its result
-Example: 
RegisterAggregate("Test", function(isFinished, context) 
	context.cnt = context.cnt or 0;
	if isFinished return context.cnt; end
	context.cnt = context.cnt + 1;
end)
-Would register a simple count function which could be called as:
-select Test("Id") from Table;
nil RegisterAggregate(name, function)

-Register a lua function as a sql function
-function def: function(context, arg1, arg2, ...)
-context (a table) is always the same table each time the function is called
nil RegisterFunction(name, function)

lua functions:

-Registers a virtual table by name that contains fields
-Name of the virtual table
-fields: should be an array, the first field will be considered the primary key example: {"Id", "Value", "Data"}
-reader:
-reader is a function defined as function(context) where context
-is a table for user data, the same context is pushed to each call of read for the same cursor
-meaning if two different cursors are reading the table there will be two different contexts
-the reader function should return an array containing the field values in order
-so for the above example it could return {1, "abc", 12.3} where the first value is the primary key "Id"
-The insertupdatedelete function is run when data is being modified for example delete, update, insert, etc is running
-if no insertupdatedelete is given then the virtual table is considered readonly
-insertupdatedelete should be defined as function(pk, data)
-where pk is the primary key being updated and the data representing the new data
-pk primary key in the above example this would be "Id", data contains a field of new data to be inserted
-so in the above example data would contain data[1] = Id, data[2] = Value, and data[3] = Data
-if data[1] is not equal to pk then the pk is being updated to a new primary key
-if data is nil then the pk is being deleted
-if pk is nil then the new data contains a completely new row
-if pk is equal to data[1] then the row is being updated
-If data should not be udpdated then the function should call error for example error("Duplicate key");
nil RegisterVirtualTable(string name, array fields, readerfunction, opt insertupdatedelete)

-Registers a table to mirror a virtual table
-name is the name of the virtual table
-array is a field of names same as RegisterVirtualTable
-The first value in the fields is considered the primary key and will be the key in the lua table as well
-fields example {"Id", "Value", "Data"}
-values are stored as: table[pk] = {"Value", "Data"}
-If only two fields is given then it will instead be stored as table[pk] = value
nil RegisterTable(string name, array fields, table)
