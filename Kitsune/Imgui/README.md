# Kitsune/Imgui — ImGui snapshot

This folder must contain a checked-in snapshot of Dear ImGui and the
`dear_bindings`-generated C API files before the project will compile
with `KITSUNE_IMGUI` enabled.

## Required files

```
imgui.h
imgui.cpp
imgui_internal.h
imgui_draw.cpp
imgui_tables.cpp
imgui_widgets.cpp
imgui_demo.cpp
imgui_impl_sdl2.h
imgui_impl_sdl2.cpp
imgui_impl_opengl3.h
imgui_impl_opengl3.cpp
imconfig.h
imgui_stdlib.h         (optional, for std::string helpers)
dcimgui.h              ← generated by dear_bindings
dcimgui.cpp            ← generated by dear_bindings
dcimgui.json           ← generated by dear_bindings (input to generate_imgui_bindings.py)
```

## How to populate this folder

### 1. Get Dear ImGui (v1.90.x or later with ErrorRecovery API)

```
git clone https://github.com/ocornut/imgui --branch v1.91.0 --depth 1 imgui_src
cp imgui_src/imgui*.h imgui_src/imgui*.cpp Kitsune/Imgui/
cp imgui_src/backends/imgui_impl_sdl2.* Kitsune/Imgui/
cp imgui_src/backends/imgui_impl_opengl3.* Kitsune/Imgui/
```

### 2. Generate the C API with dear_bindings

```
git clone https://github.com/dearimgui/dear_bindings --depth 1
cd dear_bindings
pip install -r requirements.txt
python dear_bindings.py --output ../Kitsune/Imgui/dcimgui ../Kitsune/Imgui/imgui.h
```

This produces `dcimgui.h`, `dcimgui.cpp`, and `dcimgui.json` in `Kitsune/Imgui/`.

### 3. Generate Kitsune bindings

From the repo root:

```
python Kitsune/generate_imgui_bindings.py
```

This produces:
- `Kitsune/ImguiRenderer_generated.cpp`
- `Kitsune/ImguiEnums_generated.cpp`
- `docs/imgui-renderer-api.md`
